# bench

The evidence base for expo's cost claims.

- `project/` - a dependency-free Python fixture (stdlib + `unittest`) that both
  benchmark arms edit. `python3 -m unittest discover -s . -t .` from inside it is the
  check command. It is a fixture, not part of the plugin.
- `tasks/` - one spec per benchmark task, written before either arm runs and handed to
  both verbatim.
- `results.jsonl` - the measured arms.
- `RESULTS.md` - the rendered report, regenerated by `scripts/bench.sh`.

Reproducing a task: copy `project/` to a scratch directory, `git init` and commit it as
the base state, then run one arm per copy from the same base. The method, including
what is deliberately not measured, is in [../docs/benchmark.md](../docs/benchmark.md).

`RESULTS.md` is a pure render with no hand-written lines, so CI can diff it against the
reporter's live output. A price-table change therefore fails the build until the table
is regenerated - a stale cost table is a wrong cost claim.
